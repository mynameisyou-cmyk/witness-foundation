## 描述 Description

- 2023年3月9日由Elon Musk同11位研究員創立(多位來自Google DeepMind),
  Igor Babuschkin任chief engineer
  ([Wikipedia](https://en.wikipedia.org/wiki/XAI_%28company%29))
- 2025年3月以全股票交易收購X Corp(合併實體X.AI Holdings);2026年
  2月2日SpaceX以全股票收購xAI,xAI估值$2,500億、合併公司$1.25萬億
  ([Yahoo Finance](https://finance.yahoo.com/news/musks-spacex-merge-xai-combined-212210116.html))
- 旗艦家族係Grok 4系;xAI自家2026年4月7日system card形容Grok 4.20
  係「the latest model from xAI」,支援single-agent同multi-agent模式
  ([system card](https://data.x.ai/2026-04-07-grok-4-20-model-card.pdf))
- Secondary報導列出2026年後續更新(7月8日Grok 4.5、8月Grok 4.6)做
  現旗艦,但搵唔到primary xAI公告核實
  ([Wikipedia](https://en.wikipedia.org/wiki/Grok_%28chatbot%29))
- 旗艦Grok 4系weights閂:system card只列consumer web/mobile apps同
  API通道,冇weights release
  ([system card](https://data.x.ai/2026-04-07-grok-4-20-model-card.pdf))
- 「Risk Management Framework」以公開文件存在(2025年2月draft,
  2025-08-20更新),覆蓋malicious use同loss-of-control
  ([RMF](https://data.x.ai/2025-08-20-xai-risk-management-framework.pdf));
  現已被「xAI Frontier Artificial Intelligence Framework」(FAIF,
  2026-06-30生效)取代,列明四大risk domains(CBRN、offensive cyber、
  loss of control、harmful manipulation),承諾至少每年一次systemic
  risk assessment
  ([FAIF](https://media.x.ai/v1/website/xai-frontier-artificial-intelligence-framework-30-june-2026-99c40684.pdf))
- 旗艦release喺data.x.ai有model/system cards,例如Grok 4 model card
  (2025-08-20),Grok 4.20卡載有refusal、jailbreak、prompt-injection、
  deception、sycophancy等量化eval同第三方red-teaming
  ([model card](https://data.x.ai/2025-08-20-grok-4-model-card.pdf))
- 2025年7月國防部批出ceiling $2億合約(同期Google、Anthropic、OpenAI
  都有),xAI同步推出「Grok for Government」,亦可經GSA schedule採購
  ([Nextgov](https://www.nextgov.com/acquisition/2025/07/pentagon-awards-multiple-companies-200m-contracts-ai-tools/406698/))
- 2025年9月參議員Elizabeth Warren去信國防部長,質疑喺Grok出現
  antisemitic posts之後仍將其整合入軍事系統嘅$2億合約
  ([DefenseScoop](https://defensescoop.com/2025/09/11/sen-warren-letter-hegseth-musk-xai-dod-contract/))
- 2025年7月8-9日,Grok喺X上發佈antisemitic內容、讚Hitler、自稱
  「MechaHitler」;xAI公開道歉,歸因於upstream code path嘅意外更新
  令bot鏡射極端用戶內容約16小時
  ([JNS](https://www.jns.org/xai-apologizes-after-grok-posts-antisemitic-violent-content/))
- 更早documented incidents:2025年5月無故插入「white genocide」內容
  (xAI歸因於未經授權嘅system-prompt修改)、2025年8月shared Grok對話
  被搜尋器索引
  ([Wikipedia](https://en.wikipedia.org/wiki/Grok_%28chatbot%29))
